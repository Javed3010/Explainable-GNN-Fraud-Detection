# Explainable Graph Neural Networks for Financial Fraud Detection

### Fraud Risk Propagation and Explainable AI in Financial Transaction Networks

An academic research project developed at Arizona State University for CSE 543: Information Assurance & Security.

This project investigates financial fraud detection using Graph Neural Networks (GNNs) and Explainable Artificial Intelligence (XAI). It analyzes transaction relationships within the Elliptic Bitcoin dataset to identify illicit activity, investigate fraud risk propagation, and interpret model predictions using GNNExplainer and SHAP.

The project explores homogeneous and heterogeneous graph architectures, compares graph-based approaches with traditional machine learning baselines, and evaluates fraud detection through classification metrics and explainability analysis.

**Technologies:** Python, PyTorch, Graph Neural Networks, TAGCN, GCN, GAT, GraphSAGE, SHAP, GNNExplainer, Jupyter Notebook.
