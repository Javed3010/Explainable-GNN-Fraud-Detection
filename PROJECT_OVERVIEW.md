# Project overview

**Title:** Explainable Graph Neural Networks for Fraud Risk Propagation in Financial Transaction Networks.

**Course:** CSE 543, Arizona State University (Spring 2026).

The project examines homogeneous graph neural networks and explainability for illicit transaction detection, alongside a comparative investigation of heterogeneous graph modeling. The implementation archive contains TAGCN, GNN baseline, traditional ML baseline, ablation, and plotting notebooks. The course report also discusses heterogeneous GNN experiments; this package does not claim to contain code that was not present in the supplied archive.

**Interpretability:** GNNExplainer investigates influential graph edges and features; SHAP estimates feature contributions. These are model explanations, not verified causes of illicit behavior.

**Research reference:** See the supplied CSE543 Group 2 Final Report for the literature review and citations.
